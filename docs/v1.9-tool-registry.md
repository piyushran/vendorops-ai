# V1.9 Tool Registry + Capability Model

V1.9 introduces the deterministic boundary between an agent plan and the tools that may be considered for execution.

Each registered tool declares a versioned identity, typed input/output schemas, side-effect class, risk class, required capabilities, and tenant/workspace/resource scope. Resource-scoped tools must identify the resource type they operate on.

The registry supports deterministic payload validation and capability-aware discovery. Discovery can also constrain tools by side-effect class and maximum risk. This is intentionally not an authorization decision: V1.10 will add deny-by-default authorization and policy evaluation immediately before consequential execution.

V1.9 does not execute external side effects. V1.11 remains the execution-engine milestone for idempotent adapters, retries, verification, and audit receipts.
